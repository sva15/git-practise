# Git Practice Guide

## Common Git Commands to Practice

### Basic Commands
- `git status` - Check repository status
- `git add` - Stage changes
- `git commit -m "message"` - Create a commit
- `git log` - View commit history

### Branch Commands
- `git branch` - List branches
- `git branch feature-name` - Create new branch
- `git checkout feature-name` - Switch branches
- `git checkout -b feature-name` - Create and switch to new branch

### Merge and Rebase
- `git merge branch-name` - Merge branch into current branch
- `git rebase branch-name` - Rebase current branch

### Remote Operations
- `git push origin branch-name` - Push branch to remote
- `git pull origin branch-name` - Pull changes from remote

## Practice Scenarios

1. **Create multiple branches** and switch between them
2. **Make commits** on different branches
3. **Merge branches** and resolve conflicts
4. **Revert commits** using git revert
5. **Reset changes** using git reset
