# Git Practice Repository

This is a practice repository for learning Git commands and workflows.

## Project Structure

- **src/** - Source code files
- **docs/** - Documentation
- **tests/** - Test files
- **config/** - Configuration files

## Getting Started

1. Clone the repository
2. Create branches for different features
3. Practice committing, merging, and resolving conflicts

## Tips for Practice

- Practice creating branches
- Make commits with meaningful messages
- Try merging branches
- Practice resolving merge conflicts
- Use Git commands like log, diff, status, etc.
